# Contextual insertion

Evaluate a model, pick a surface, and use **Shift+A** in the viewport. Choose an item and an editable destination,
then configure its parameters and placement. The palette shows unavailable libraries with a reason.

**G** drags in the captured placement plane; **R** spins about its origin; **F** flips the mating direction.
The inspector also accepts X/Y and normal offsets, spin, and existing named anchors for separate Components.
Navigation keeps the captured placement frame. Enter in a numeric field accepts that field; Enter in the viewport
or **Commit** applies a successfully evaluated candidate. Escape discards the draft.

Primitives add to the chosen finished Part or ordinary positive source statement. Holes subtract from that target.
Hardware becomes a separate Component in the containing Assembly or document root. Shared definitions list every
current affected instance and require explicit shared-scope approval. A fixed capture follows owner placement;
a named attachment follows its existing anchor. Fixed holes do not rematch a surface after geometry changes.

Commit adds imports, helpers, geometry and references in one source transaction. One Undo restores the original
bytes; Redo recreates them. Save remains a separate action. An included destination must be an explicitly selected,
already open writable user file. **Open source** navigates to a proven range; evaluate the intended root and restart
Add to choose that destination. Vendor library files are unavailable as insertion destinations.

Source, dependency, catalog, library search-order and model changes cancel the draft. Commit requires the exact
shown candidate and current inputs. A later ordinary evaluation failure preserves the committed source and Undo.
The preview is labelled as uncommitted and uses a separate process; its pixels cannot be selected or exported.

The initial native SCAD preview supports captured includes/use and deterministic native expressions. External
geometry/data/font/Python inputs and unseeded random calls are unavailable. Interleaved Part declarations,
ambiguous/repeated ordinary leaf statements, unsupported frames and import conflicts produce a reason. Generated
helpers preserve original Customizer fields; a wrapper that would precede a later field is unavailable.

The shipped catalogs contain four builtins, a BOSL2 threaded hole and three BOLTS hardware families. Install and
bind those libraries separately using the provider configuration described in [component providers](component-providers.md).
This feature does not install libraries, expand loops, clone definitions or edit tagged subtraction internals.
